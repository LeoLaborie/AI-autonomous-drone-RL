
# AI-autonomous-drone-RL
The goal of this project is to create fast, accurate, cheap autonomous drone for military purpose. 
This project implements an AI-driven autonomous drone system utilizing Reinforcement Learning (RL) techniques. It focuses on developing and training a controller for drones 

## Installation

To set up the project locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/LeoLaborie/AI-autonomous-drone-RL.git
    cd AI-autonomous-drone-RL
    ```
2.  Load it in Unity.
  download ML-agents
  run it
    
## Features

*   Reinforcement Learning (RL) framework for autonomous drone control.
*   Support for adaptive training methodologies.
*   Integration of self-play capabilities for robust model development.

## Tech Stack

*   **Languages:** ASP.NET, C#, Python
